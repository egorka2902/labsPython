## Что из себя представляет проект (лаба)

Привет! Это простой проект, который состоит из двух основных модулей:
- **calculator** - это такой калькулятор в стиле RPN (Reverse Polish Notation, обратная польская запись). Всё как у взрослых: операнды пишутся перед оператором.
- **convert** - конвертер единиц измерения. Он умеет работать с температурой, длиной и массой.

## Сборка проекта

Чтобы установить проект локально и начать работу, просто выполни в консоли:
```bash
pip install -e .
```

## Запуск тестов

Для проверки всего проекта используй pytest:
```bash
python -m pytest
```

У нас есть несколько файлов с тестами:
- `test_conv.py` - тут тесты для конвертера (как положительные, так и отрицательные сценарии)
- `test_calculator.py` - тесты для калькулятора

## Как работает RPN калькулятор

Алгоритм работы калькулятора основан на принципе **RPN** (обратная польская нотация). Всё работает вот так:

1. Операнды (числа) записываются перед оператором.
2. Когда ты вводишь число, оно помещается на специальный стек.
3. Когда приходит оператор (`+`, `-`, `*`, `/`), верхние элементы стека извлекаются, операция выполняется, а результат кладётся обратно на стек.
4. Итоговый результат берётся после того, как выражение завершено (или после ввода знака `=` если бы он был, но у нас просто в конце строки).

**Пример**: выражение `1 2 +` означает `(1 + 2)`, и результат будет `3`.

Также поддерживаются:
- Унарные плюсы и минусы (`+5`, `-3`)
- Приоритет операций (умножение и деление считаются раньше сложения и вычитания)
- Скобки для явного задания порядка вычислений

## Конвертер единиц измерения

Основная функция конвертера - это `change(f, t, val)`. Она принимает три параметра:
- `f` - начальная единица измерения (from)
- `t` - целевая единица измерения (to)
- `val` - значение, которое нужно конвертировать

Конвертер умеет работать с тремя типами величин:
1. **Температура**: градуса Цельсия (`c`), Фаренгейта (`f`) и Кельвина (`k`).
2. **Длина**: миллиметры (`mm`), сантиметры (`cm`), метры (`m`) и километры (`km`).
3. **Масса**: граммы (`g`) и килограммы (`kg`).

Внутри для температуры используется вспомогательная функция `conv_t(val, f, t)`, которая сначала переводит всё в градусах Цельсия, а потом в нужную единицу.

## Округление результатов

При вычислении через функцию `calc()` или `change()` результат всегда округляется до 2 символов после запятой. То есть если получается 1.478, то на выходе будет 1.48.

## Описание функций и ошибок

### Модуль calculator (`toolkit/calculator.py`)

В этом модуле есть три основные функции:

1. **`tok(s: str)`** - функция токенизации выражения. Она разбивает строку с выражением на отдельные токены (числа, операторы, скобки). При этом она убирает пробелы и проверяет, что в строке нет лишних символов.
   
   **Возможные ошибки (исключения `CalcErr`):**
   - `"пустое выражение"` - если передана пустая строка или строка только с пробелами.
   - `"че за символы"` - если в выражении есть недопустимые символы (не цифры, не операторы и не скобки).

2. **`validate(toks)`** - функция проверки выражения на ошибки после токенизации. Проверяет, что выражение синтаксически корректно: нет ли двух операторов подряд, не заканчивается ли выражение оператором и так далее.
   
   **Возможные ошибки (`CalcErr`):**
   - `"пустой список токенов"` - если после разделения на токены список оказался пустым.
   - `"в конце выражения оператор"` - если последнее в выражении что-то кроме числа (например, `2 +`).
   - `"два оператора рядом: {operator1} и {operator2}"` - если два оператора стоят подряд без числа между ними (например, `2 + * 3`).

3. **`calc(expr)`** - главная функция вычисления выражения в стиле RPN. Она использует токенизацию (`tok`) и валидацию (`validate`), а затем строит обратный польский записи и вычисляет результат с помощью стека.
   
   **Возможные ошибки (`CalcErr`):**
   - `"че то со скобками"` - если скобки несогласованы (например, открыта одна, а закрыта другая не та или наоборот).
   - `'несогласованные скобки'` - если в конце обработки стека остались незакрытые скобки.
   - 'деление на 0' - если происходит попытка разделить на ноль.
   - 'неправильно выражение' - если после вычислений в стеке осталось не одно значение (значит, выражение было составлено неправильно).

### Модуль convert (`toolkit/convert.py`)

В этом модуле есть две основные функции:

1. **`conv_t(val, f, t)`** - внутренняя функция для конвертации температуры. Она принимает значение `val`, начальную единицу `f` и целевую `t`. Сначала переводит всё в градусах Цельсия, а потом в нужной формат.
   
   **Возможные ошибки (исключения `convErr`):**
   - `"ниже абсолютного нуля"` - если попытаться получить температуру ниже абсолютного нуля (например, меньше -273.15 для Цельсия, меньше -459.67 для Фаренгейта или меньше 0 для Кельвина).

2. **`change(f, t, val)`** - главная функция конвертации единиц измерения. Она принимает начальную единицу `f`, целевую `t` и значение `val`. Поддерживает длину, массу и температуру.
   
   **Возможные ошибки (исключения `convErr`):**
   - `"Отрицательное значение не поддерживается"` - если пытаются конвертировать отрицательное значение для длины или массы (например, `-5.5` метров в километры). В физике длина и масса не могут быть отрицательными.
   - `'ошибка в единицах измерения'` - если переданы несуществующие или несоответствующие друг другу единицы измерения.

## Что проверяется в тестах

В файле `test_conv.py`:
- **test1-test7** - тесты нормальной конвертации (положительные сценарии для длины, массы и температуры).
- **test_1-test_5** - проверки на ошибки: отрицательные значения для длины/массы, попытки получить температуру ниже абсолютного нуля.

В файле `test_calculator.py`:
- Хорошие тесты (`test_addition`, `test_subtraction`, `test_multiplication`, `test_division`, `test_priority`, `test_unary_minus`, `test_unary_plus`, `test_floats`, `test_spaces_ignored`, `test_complex_expression`) - проверяют корректность вычислений.
- Плохие тесты (`test_empty`, `test_spaces`, `test_character`, `test_missing`, `test_two`, `test_zero`, `test_start`) - проверяют, что калькулятор правильно реагирует на пустые выражения, лишние символы, деление на ноль и несогласованные операторы.
