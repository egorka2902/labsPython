## RPN

Алгоритм работает по принципу **RPN**:

1. Операнды записываются перед оператором
2. При вводе числа оно помещается на стек
3. При вводе оператора (+, -, *, /) верхние элементы стека извлекаются, операция выполняется, результат обратно на стек
4. Результат берётся после ввода `=`

**Пример**: `1 2 +` = (1 + 2) = 3

## Конвертер
Функция change(f, t, val) конвертирует значения между единицами.

## Округление
При вычисление через calc() или change() результат округляется до 2 символов после запятой
